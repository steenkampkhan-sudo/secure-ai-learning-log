neural network; machine learning models that mimic the function of the brain.
neurons; A unit that ingests a group of weighted inputs, has an activation function applied and returns an output.
weights; Values that control the strength of the connection between two neurons.
bias; Intentional constants placed attached to neurons and added to the weighted input prior to application of the activation function.
input layer; Holds the base data your model will train on, every neuron in this layer represents a unique attribute.
output layer; Final layer in a neural network, returns an output representing the model's best prediction.
